# Latihan JLPT N4 — Renshuu

Aplikasi latihan soal JLPT N4 (tema Neo-Brutal): 274 soal dari 5 set ujian asli (2014, 2016, 2017, 2018, 2021).
Satu soal per layar, pilihan diacak, pembahasan langsung, hasil per kategori + ulasan soal yang salah.

Buka `index.html` di peramban, atau lewat GitHub Pages bila sudah diaktifkan.
